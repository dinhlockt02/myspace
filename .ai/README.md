# AI Context

Platform-agnostic context files for AI assistants.

## Structure

- `context/` - Project context, architecture docs, conventions
- `prompts/` - Reusable prompt templates
- `templates/` - Code templates, boilerplate examples

## Usage

Any AI tool can reference these files. Tool-specific configs (`.cursorrules`, `.github/copilot-instructions.md`, `opencode.json`) should point here for shared context.
