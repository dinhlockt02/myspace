# Implementation Plan: Developer Environment Onboarding and AI Skills Setup

**Branch**: `006-setup-dev-environment` | **Date**: 2026-10-12 | **Spec**: [specs/006-setup-dev-environment/spec.md](spec.md)

**Input**: Feature specification from `specs/006-setup-dev-environment/spec.md`

## Summary

Implement an automated, guided onboarding and development environment setup system for the Myspace monorepo. The solution employs a dual-mode hybrid architecture: a modular root CLI script (`scripts/setup-dev.sh` wired to `pnpm run setup`) for direct terminal execution, and a companion AI agent skill (`.agents/skills/dev-onboarding/SKILL.md`) for conversational onboarding and troubleshooting. The system audits host workstation prerequisites (Node.js, pnpm, Go, Docker engine, Compose), bootstraps monorepo dependencies, provisions local containerized backing services (`dynamodb-local` via `docker-compose.yml`), instantiates safe local environment configurations from `.env.example` templates with zero cloud credentials required, audits the complete AI-native SDLC suite, executes an end-to-end smoke test, and persists diagnostic reports in `.specify/reports/`.

## Technical Context

**Language/Version**: Node.js 20+, Go 1.22+, Bash 5+

**Primary Dependencies**: pnpm (>= 9.0.0), Nx (>= 20.0.0), Docker Engine (>= 24.0.0), Docker Compose (>= 2.20.0)

**Storage**: Local Docker Compose container for DynamoDB Local (`amazon/dynamodb-local:latest`); local filesystem for gitignored configuration (`.env`) and reports (`.specify/reports/`)

**Testing**: Automated smoke tests via Nx targets (`pnpm nx run-many -t lint,test,build`), Go test suites, and shell diagnostic scripts

**Target Platform**: Linux, macOS, Windows WSL

**Project Type**: Developer Tooling / Automation Scripts & AI Agent Skill

**Performance Goals**:
- Host prerequisites audit completed in < 30 seconds
- Fresh clone to fully operational ready-to-code state in < 15 minutes
- Automated verification smoke test completed in < 5 minutes

**Constraints**:
- Strictly zero committed secrets or cloud credentials (safe local mock defaults only)
- Zero external cloud access required for local development and initial verification
- Idempotent execution (safe to run multiple times without state corruption)
- Support non-root / user-level execution without requiring unprompted `sudo`

**Scale/Scope**: Repository-wide onboarding covering `apps/idea-collector` (frontend + backend), `apps/commifra`, and repository AI skills
